# 让网络世界更有生气 ✨

Peeklings 是一群小巧的动画角色。它们可以安静、俏皮地来到网站上，却不会妨碍你。来认识它们，构想属于你的角色，或与我们一起创造接下来的一切。

## 什么是 Peekling？

Peekling 是一个小巧的动画伙伴，拥有自己的外观、个性，以及回应周围页面的方式。它陪伴在网站一旁，为页面增添一点活力，同时让页面保持原本的样子。

在这些角色背后，Peekling 是一个开源的浏览器运行时，用于承载小巧、纯数据驱动的动画角色。它让角色能够移动和回应，同时不会把遥测信息或页面数据发送到后端。

每个部分都有清晰的职责。引擎负责加载和渲染。Pack 保存角色的美术资源和能力。由开发者掌控的 Plan 决定角色何时作出反应。Skills 则为创建、集成、审核和分享 Peekling 的开发者与艺术家提供工作流程。

### 原则

- **一个引擎，多种载体。** 同一个运行时可以把 Peekling 带到网站、未来的桌面应用或浏览器扩展中。
- **角色是数据，不是代码。** Pack 包含美术资源和经过验证的动画数据，不能运行脚本，也不能接管宿主页面。
- **宿主始终掌控一切。** 开发者选择 Pack、Plan、策略和呈现方式。访客无需账户或后端服务，也能让所有 Peekling 休息。
- **无遥测，无后端。** 运行时在浏览器中完成工作。项目可以固定软件包版本，也可以自行托管文件。
- **Skills 是可移植的文件夹。** 每个工作流程都位于一个包含 `SKILL.md` 的文件夹中，开发者和艺术家可以配合兼容的智能体使用。
- **许可证清晰明确。** 运行时、工具、官方 Pack 和 Skills 均采用 Apache-2.0。每个 Pack 都会声明其美术资源的权利。

## 欢迎每一个人

无论你是来认识这些角色、学习新事物、绘画、写作、制作动画、编程、教学、为公司打造产品，还是只想看看这里正在孕育什么，我们都很高兴与你相遇。

学生和初次尝试创作的人可以自由探索。艺术家和作家可以构想新的个性。开发者可以让互动鲜活起来。公司可以帮助数字空间变得更有人情味。只是喜欢身边有个小伙伴的人，也同样是这幅图景中不可缺少的一部分。

无论是什么带你来到这里，有好奇心就足以开始。

## 参与其中

你不需要带着代码或完整的想法来到这里。选择一个让你感到自在的方向：

- **构建运行时**，前往 [peekling-engine](https://github.com/peekling/peekling-engine)。
- **绘制、制作动画或改进角色**，前往 [peekling-characters](https://github.com/peekling/peekling-characters)。
- **为开发者或艺术家创建工作流程**，前往 [peekling-skills](https://github.com/peekling/peekling-skills)。
- **参与塑造未来的桌面应用**，前往即将推出的 [peekling-desktop](https://github.com/peekling/peekling-desktop)。
- **把 Peekling 带进 Chrome**，前往即将推出的 [peekling-chrome-extension](https://github.com/peekling/peekling-chrome-extension)。

为你希望看到成长的项目点亮星标。Issue、目标明确的 pull request、角色创意、美术、故事和文档都能提供帮助。

## 认识 Peek

Peek 是第一个 Peekling。它好奇又开朗，会跟随指针，也会庆祝每一个小小的成功。

Peekling 是一个可以陪伴在网站周围的小角色，安静、俏皮，却不会妨碍你。

你可以创建自己的 Peekling，并把它添加到你的网站中。[按照这份指南](https://github.com/peekling/peekling-characters#make-a-character)即可开始。

## 一起成长

Peekling 正在一次公开一个部分，逐步成长。随着更多部分开放，我们希望这段旅程自然流畅：认识一个角色、了解它、试用它、把它添加到网站、赋予它自己的风格，再把你的收获分享给社区。

这段旅程的某些部分仍在前方。我们只会在它们准备好时推出，而且每一个公开的部分都应该让下一位参与者更容易加入。

Peekling 是开源项目，采用 Apache 2.0 许可证。
